# Company Database Scraper API – code examples

Examples for every Company Database endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/default.sh`](curl/default.sh) | `bash default.sh` |
| PHP | [`php/default.php`](php/default.php) | `php default.php` |
| C# | [`csharp/Default.cs`](csharp/Default.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/default.go`](go/default.go) | `go run default.go` |
| Java | [`java/DefaultExample.java`](java/DefaultExample.java) | `java DefaultExample.java` |
| Ruby | [`ruby/default.rb`](ruby/default.rb) | `ruby default.rb` |
| Node.js | [`nodejs/default.mjs`](nodejs/default.mjs) | `node default.mjs` |
